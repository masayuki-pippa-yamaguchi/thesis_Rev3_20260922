\chapter{考察：倒産ステージ推移の構造的解釈}
\label{chap:structural_interpretation}


本章では，9.1～9.6節（日本企業）および9.7～9.12節（英国企業）で得られた
Ordered Logit 推定結果を踏まえ，新電力企業の倒産ステージが
どのような構造的メカニズムによって進行するのかを体系的に解釈する。
本研究で採用した四要素モデル（収益性 $\mu$，負債負担 $D$，
外部ショック感応度 $\sigma$，支援能力 $S$）は，
新電力企業の財務構造・市場構造・制度構造を抽象化した理論枠組みであり，
各要素が倒産ステージの推移にどのように寄与するかを明示的に捉えることができる。

本章では，まず四要素それぞれが倒産ステージを押し上げる（あるいは抑制する）
構造的理由を検討し，次に Ordered Logit の閾値構造が示す倒産の段階性を整理する。
さらに，日本企業と英国企業の比較を通じて，
市場構造・制度環境の違いが倒産ステージ推移にどのような影響を与えるかを考察する。
最終的に，新電力企業の倒産は単発のショックではなく，
ビジネスモデルの構造的脆弱性\footnote{本研究における「構造的脆弱性」とは，
新電力企業が制度構造・市場構造・財務構造のいずれにおいても
倒産リスクを内包する状態を指す。具体的には，
（1）薄利構造により収益性 $\mu$ が低く，
（2）参入初期投資や資本規模の小ささから負債比率 $D$ が高く，
（3）スポット市場依存度の高さにより外部ショック感応度 $\sigma$ が大きく，
（4）独立系が多く親会社支援が乏しいため支援能力 $S$ が低い，
という四要素の組み合わせによって，
潜在変数 $y^*$ が恒常的に cutpoint に近い位置に留まり，
外生ショックが発生した際に倒産ステージが非線形的に進行しやすい構造を指す。}によって規定されるという本研究の中心的結論を提示する。

% 10.1 資産成長率（$\mu$）が倒産ステージを押し上げる構造的理由
% ============================================================

\section{資産成長率（$\mu$）が倒産ステージを押し上げる構造的理由}

本節では，四要素モデルの第1要素である資産成長率（収益性）$\mu$ が，
倒産ステージの推移にどのような構造的影響を与えるかを検討する。
$\mu$ は企業価値の期待成長率を表す指標であり，
企業が将来にわたりどれだけ資産を増加させる能力を持つかを示す。
Merton 型モデルにおいては，企業価値プロセスの drift\footnote{
本研究では，企業価値の推移を「確率過程」として捉える。
確率過程とは，時間とともにランダムな揺らぎを伴って変化する量を記述する枠組みであり，
ブラウン運動に見られるようなランダムな変化を基礎としている。
幾何ブラウン運動（GBM）は，この確率過程の代表例であり，
drift はその平均的な変化方向（期待的な傾き）を表す構造的パラメータである。}として位置づけられ，
企業価値が負債水準に対してどの程度上昇しうるかを規定する中心的パラメータである。

\subsection*{10.1.1 理論モデルにおける $\mu$ の役割}

Merton 型倒産モデルでは，企業価値 $V_F$ は次式に従うと仮定される。



\[
dV_F = \mu V_F dt + \sigma_V V_F dW_t.
\]



ここで $\mu$ は企業価値の期待成長率であり，
企業価値が時間とともにどの方向へ推移するかを決定する。
倒産距離（Distance to Default）は



\[
DD = \frac{\ln(V_F/D) + (\mu - \frac{1}{2}\sigma_V^2)T}{\sigma_V\sqrt{T}}
\]



で与えられるため，$\mu$ が大きいほど倒産距離は拡大し，
倒産確率は低下する。
すなわち，$\mu$ は倒産ステージを押し下げる方向に作用する構造的要素である。

\subsection*{10.1.2 実証モデルにおける $\mu$ の写像}

本研究では，企業価値 $V_F$ を直接観測できないため，
総資産の成長率（asset\_growth）を $\mu$ の実証的 proxy として採用した。
総資産の対数差分は



\[
\ln(A_t) - \ln(A_{t-1}) \approx \frac{A_t - A_{t-1}}{A_{t-1}}
\]



の近似関係にあり，いずれも企業価値の期待成長率と同じ経済的意味を持つ。
したがって，asset\_growth は理論モデルの $\mu$ を
財務データに写像した指標として機能する。

\subsection*{10.1.3 倒産ステージを押し上げる構造的メカニズム}

資産成長率が低下すると，企業価値の期待成長率が低下し，
倒産距離が縮小する。
Ordered Logit モデルの潜在変数 $y^*$ は



\[
y^* = \beta_\mu \mu + \beta_D D + \beta_\sigma \sigma + \beta_S S
\]



で与えられるため，$\mu$ の低下は $y^*$ を押し下げ，
cutpoint $\tau_1, \tau_2$ を跨ぐ確率を高める。
その結果，

\begin{itemize}
    \item stage 0（存続）から stage 1（財務悪化）への移行確率が上昇し，
    \item stage 2（倒産ステージ）の確率も急上昇する。
\end{itemize}

すなわち，資産成長率の低下は倒産ステージを押し上げる方向に作用する。

\subsection*{10.1.4 新電力市場における構造的意味}

新電力企業は，固定費の高い小売事業を営む一方で，
利益率が薄く，資産成長率が構造的に低い傾向がある。
特に，

\begin{itemize}
    \item JEPX スポット価格の急騰，
    \item 燃料価格の高騰，
    \item 需給調整市場の制度変更，
\end{itemize}

といった外生ショックが発生すると，
営業利益が急速に悪化し，資産成長率が低下する。
この低下が潜在変数 $y^*$ を押し下げ，
倒産ステージの進行を促す構造的メカニズム\footnote{
本研究でいう「構造的メカニズム」とは，
外生ショックが新電力企業の損益構造に直結し，
その影響が四要素モデル（$\mu, D, \sigma, S$）を通じて
潜在変数 $y^*$ に反映され，倒産ステージを押し上げる一連の因果連鎖を指す。
たとえば JEPX スポット価格が急騰すると，
（1）調達費用が増加し営業利益が悪化し，
（2）資産成長率 $\mu$ が低下し，
（3）キャッシュフローの不安定化により外部ショック感応度 $\sigma$ が上昇し，
（4）負債返済負担が相対的に重くなり負債比率 $D$ の影響が強まり，
（5）支援能力 $S$ が低い企業では緩衝材が働かず，
結果として潜在変数 $y^*$ が cutpoint に接近し，
倒産ステージ（stage 1 → stage 2）が非線形的に進行する。
このように，新電力企業は外生ショックが財務構造に直接的に作用する制度的特徴を持つため，
ショックが倒産ステージの進行に直結しやすい。}が働く。

したがって，資産成長率 $\mu$ は単なる財務指標ではなく，
新電力企業のビジネスモデルの脆弱性を反映する構造的要素であり，
倒産ステージ推移の根本的な決定要因として位置づけられる。

\section{負債比率（$D$）が倒産閾値として機能するメカニズム}

本節では，四要素モデルの第2要素である負債比率 $D$ が，
倒産ステージの推移にどのような構造的影響を与えるかを検討する。
負債比率は，企業が保有する資産のうちどれだけが負債によって賄われているかを示す
財務健全性の基本指標であり，企業価値が負債水準に対してどの程度余裕を持つかを
直接的に規定する要素である。

\subsection*{10.2.1 理論モデルにおける倒産閾値の構造}

Merton 型倒産モデルでは，倒産は企業価値 $V_F$ が負債水準 $D$ を下回るときに発生する。
すなわち，倒産閾値（default threshold）は負債水準そのものであり，



\[
V_F(T) \leq D \quad \Rightarrow \quad \text{default}
\]



という単純かつ明確な構造を持つ。
このため，負債比率が高い企業ほど倒産閾値が相対的に押し上げられ，
企業価値が同じ水準であっても倒産距離（Distance to Default）は短くなる。

倒産距離の式



\[
DD = \frac{\ln(V_F/D) + (\mu - \frac{1}{2}\sigma_V^2)T}{\sigma_V\sqrt{T}}
\]



からも明らかなように，$D$ が増加すると分子が縮小し，
倒産距離は構造的に短縮される。
したがって，負債比率 $D$ は倒産閾値を押し上げる方向に作用する
「構造的リスク要因」である。

\subsection*{10.2.2 実証モデルにおける $D$ の写像}

本研究では，企業価値 $V_F$ や負債の市場価値を直接観測できないため，
財務諸表に基づく負債比率



\[
D_{i,t} = \frac{\text{Liabilities}_{i,t}}{\text{Assets}_{i,t}}
\]



を倒産閾値の代理変数（proxy）として採用した。
この指標は，負債水準が資産に対してどれだけ重いかを示すため，
理論モデルの倒産閾値 $D$ を財務データに写像したものとして機能する。

Ordered Logit モデルの潜在変数 $y^*$ は



\[
y^* = \beta_\mu \mu + \beta_D D + \beta_\sigma \sigma + \beta_S S
\]



で与えられるため，負債比率の上昇は $y^*$ を押し下げ，
cutpoint $\tau_1, \tau_2$ を跨ぐ確率を高める。
その結果，倒産ステージの進行確率が構造的に上昇する。

\subsection*{10.2.3 倒産ステージを押し上げる構造的メカニズム}

負債比率が高い企業は，以下の理由により倒産ステージが進行しやすい。

\begin{enumerate}
    \item \textbf{倒産閾値が押し上げられる}  
          負債比率の上昇は，企業価値が下回るべき閾値を高めるため，
          同じ企業価値でも倒産距離が短縮される。

    \item \textbf{財務柔軟性が低下する}  
          負債返済負担が重くなることで，外生ショックに対する耐性が低下し，
          $\sigma$ の影響が増幅される。

    \item \textbf{資金調達コストが上昇する}  
          負債比率が高い企業は信用リスクが高まり，
          新規調達が困難となり，キャッシュフローの悪化が加速する。

    \item \textbf{潜在変数 $y^*$ が cutpoint に近づく}  
          $D$ の上昇は $y^*$ を押し下げるため，
          stage 1（財務悪化）や stage 2（倒産）の確率が急上昇する。
\end{enumerate}

これらの構造的要因により，負債比率の上昇は倒産ステージを押し上げる方向に作用する。

\subsection*{10.2.4 新電力市場における構造的意味}

新電力企業は，以下の理由により負債比率が構造的に高くなりやすい。

\begin{itemize}
    \item 参入初期の設備投資・システム投資が大きい\footnote{
    新電力は，発電設備を保有しなくても小売事業に参入できるため，
    参入障壁は従来電力会社に比べて低い。しかし，
    「設備投資・システム投資」とは発電設備ではなく，
    需給管理システム，顧客管理システム，料金計算システム，
    スマートメーター連携基盤など，小売事業運営に不可欠な
    IT・システム基盤への初期投資を指す。
    なお，自前の発電設備（太陽光・バイオマス等）を保有する新電力は
    全体の一部に限られ，経済産業省の公表資料によれば，
    FIT・非FITを含む自社発電設備を有する新電力は
    全体の約2～3割程度にとどまり，多くの新電力は市場調達依存型である。
    このため，発電設備を持たない企業でも，
    小売事業運営に必要なシステム投資が初期負担となり，
    負債比率が高まりやすい構造が生じる。}  
    \item 収益率が低く，内部留保が蓄積しにくい  
    \item 需給調整市場やスポット市場の価格変動によりキャッシュフローが不安定  
    \item 価格競争により利益率が薄く，資産成長率が低い  
\end{itemize}

これらの構造的特徴により，新電力企業は負債依存度が高くなりやすく，
倒産閾値が恒常的に押し上げられた状態で事業を運営している\footnote{
新電力企業の負債依存度の高さは，帝国データバンクによる
「新電力会社」事業撤退動向調査（2024年3月）においても確認されている。
同調査では，2021年4月時点で登録されていた新電力706社のうち，
2024年3月時点で「撤退」「倒産・廃業」に至った企業が累計119社（構成比16.9％）と，
2年間で約7倍に急増したと報告されている。
倒産企業の多くは，卸電力市場からの仕入れ依存度が高く，
市場価格高騰に伴う逆ザヤ構造により資金繰りが悪化し，
負債負担の増大が倒産の直接要因となったとされる。
また，2021～2023年の間に契約停止・撤退・倒産に至った企業は195社（27.6％）に達し，
新電力の約4社に1社が市場から退出したことが示されている。
これらの事実は，新電力企業が構造的に負債依存度の高い状態で事業を運営していること，
そして外生ショックが負債負担を増幅し倒産閾値を押し上げる構造的脆弱性を抱えていることを裏付けるものである。}。
そのため，外生ショックが発生すると潜在変数 $y^*$ が急速に低下し，
倒産ステージが短期間で進行する。

したがって，負債比率 $D$ は新電力企業の倒産リスクを規定する
中心的な構造要因であり，倒産閾値として機能することで
倒産ステージ推移の根本的メカニズムを形成している。

\section{外部ショック感応度（$\sigma$）が新電力の脆弱性を増幅する構造}

本節では，四要素モデルの第3要素である外部ショック感応度 $\sigma$ が，
新電力企業の倒産ステージ推移にどのような構造的影響を与えるかを検討する。
$\sigma$ は，企業価値が外部環境の変動に対してどれほど敏感に反応するかを示す
ボラティリティ指標であり，外生ショックが企業価値に与える影響の大きさを
直接的に規定する構造パラメータである。

\subsection*{10.3.1 理論モデルにおける $\sigma$ の位置づけ}

Merton 型モデルでは，企業価値プロセスは



\[
dV_F = \mu V_F dt + \sigma_V V_F dW_t
\]



に従うとされ，$\sigma_V$ は企業価値のボラティリティを表す。
$\sigma_V$ が大きいほど，企業価値は外部ショックに対して大きく変動し，
倒産距離（Distance to Default）は構造的に縮小する。

倒産距離の式



\[
DD = \frac{\ln(V_F/D) + (\mu - \frac{1}{2}\sigma_V^2)T}{\sigma_V\sqrt{T}}
\]



からも明らかなように，$\sigma_V$ が増加すると分母が拡大し，
倒産距離は急速に短縮される。
すなわち，外部ショック感応度 $\sigma$ は倒産ステージを押し上げる方向に作用する
「ショック増幅要因」である。

\subsection*{10.3.2 実証モデルにおける $\sigma$ の写像}

本研究では，企業価値のボラティリティ $\sigma_V$ を直接観測できないため，
市場価格の変化率や変動幅を用いて外部ショック感応度を proxy 化した。
具体的には，

\begin{itemize}
    \item 絶対変化（abs\_change）
    \item ローリング標準偏差（roll\_std\_3m）
\end{itemize}

を外部ショック感応度の代理変数として採用した。
これらは，市場価格の急変動が企業の損益にどれほど影響するかを捉える指標であり，
理論モデルの $\sigma_V$ を財務データに写像したものとして機能する。

Ordered Logit モデルの潜在変数 $y^*$ は



\[
y^* = \beta_\mu \mu + \beta_D D + \beta_\sigma \sigma + \beta_S S
\]



で与えられるため，外部ショック感応度の上昇は $y^*$ を押し下げ，
cutpoint $\tau_1, \tau_2$ を跨ぐ確率を高める。
その結果，倒産ステージの進行確率が構造的に上昇する。

\subsection*{10.3.3 倒産ステージを押し上げるショック増幅メカニズム}

外部ショック感応度が高い企業は，以下の理由により倒産ステージが進行しやすい。

\begin{enumerate}
    \item \textbf{外生ショックが企業価値に直接的に作用する}  
          $\sigma$ が大きいほど，市場価格の急騰・急落が企業価値に強く反映され，
          倒産距離が急速に縮小する。

    \item \textbf{ショックの累積が財務指標を悪化させる}  
          高い $\sigma$ はキャッシュフローの不安定化を招き，
          営業利益や自己資本比率の悪化を通じて潜在変数 $y^*$ を押し下げる。

    \item \textbf{負債比率との相互作用によりリスクが増幅される}  
          負債比率 $D$ が高い企業ほど，外部ショックの影響が増幅され，
          $y^*$ が cutpoint に急速に近づく。

    \item \textbf{倒産ステージの非線形的進行を引き起こす}  
          $\sigma$ の上昇は，stage 1（財務悪化）から stage 2（倒産）への移行を
          非線形的に加速させる\footnote{
      本研究でいう「非線形的進行」とは，外部ショック感応度 $\sigma$ の上昇が
      潜在変数 $y^*$ を cutpoint に近づけることで，
      倒産ステージの確率が連続的ではなく急峻に変化する Ordered Logit 特有の構造を指す。
      具体的には，$y^*$ が cutpoint $\tau_2$ に接近すると，
      ロジスティック分布の性質により倒産ステージ（stage 2）の確率が
      わずかな変化で急激に跳ね上がる。
      そのため，外生ショックにより $\sigma$ が上昇すると，
      （1）市場価格変動の影響が増幅され，
      （2）$y^*$ が短期間で cutpoint に到達し，
      （3）倒産ステージが「段階を飛び越えるように」進行する。
      この急峻な確率変化こそが非線形的進行であり，
      線形モデルでは説明できない倒産ステージの跳躍的な移行を意味する。}。
\end{enumerate}

これらの構造的要因により，外部ショック感応度の上昇は倒産ステージを押し上げる。

\subsection*{10.3.4 新電力市場における構造的意味}

新電力企業は，以下の理由により外部ショック感応度が構造的に高くなる。

\begin{itemize}
    \item スポット市場依存度が高く，JEPX 価格急騰の影響を直接受ける  
    \item 調達構造が固定費化されておらず，市場価格変動が損益に直結する  
    \item 需給調整金制度の変更がキャッシュフローに即時影響する  
    \item 利益率が薄く，ショック耐性が低い  
\end{itemize}

これらの制度的特徴により，新電力企業は外部ショックに対して脆弱であり，
$\sigma$ が高い状態で事業を運営している。
そのため，市場価格の急騰や制度変更が発生すると，
潜在変数 $y^*$ が急速に低下し，倒産ステージが短期間で進行する。

したがって，外部ショック感応度 $\sigma$ は新電力企業の倒産リスクを規定する
中心的な構造要因であり，ショック増幅メカニズムを通じて
倒産ステージ推移の本質的な決定要因となっている。

% 10.4 支援能力（$S$）が倒産回避に果たす役割
% ============================================================

\section{支援能力（$S$）が倒産回避に果たす役割}

本節では，四要素モデルの第4要素である支援能力 $S$ が，
倒産ステージ推移にどのような構造的影響を与えるかを検討する。
支援能力 $S$ は，企業が外部から受け得る財務支援や信用補完の余力を表す指標であり，
企業価値が負債水準に接近した際に倒産を回避するための「緩衝材」として機能する。
四要素モデルの中で，倒産ステージを押し下げる方向に作用する唯一の構造要素である。

\subsection*{10.4.1 理論モデルにおける支援能力の位置づけ}

Merton 型モデルでは，倒産は企業価値 $V_F$ が負債水準 $D$ を下回るときに発生する。
支援能力 $S$ は，この倒産閾値を押し下げる効果を持ち，



\[
V_F(T) \leq D - S \quad \Rightarrow \quad \text{default}
\]



という形で倒産境界を緩和する役割を果たす。
すなわち，支援能力が大きいほど倒産閾値は低くなり，
企業価値が同じ水準であっても倒産距離（Distance to Default）は拡大する。

倒産距離の式に支援能力を組み込むと，



\[
DD = \frac{\ln(V_F/(D-S)) + (\mu - \frac{1}{2}\sigma_V^2)T}{\sigma_V\sqrt{T}}
\]



となり，$S$ の増加は分子を拡大し，倒産距離を構造的に伸ばす。
したがって，支援能力 $S$ は倒産ステージを押し下げる方向に作用する
「閾値緩和要因」である。

\subsection*{10.4.2 シミュレーションモデル\footnote{日本企業の実証モデルでは支援能力 $S$ を観測できないため
$S=0$ として推定している。本節では，理論モデルおよびシミュレーションにおける
$S$ の構造的役割を整理するものであり，実証推定とは区別して扱う。}
における $S$ の写像}

日本企業では，支援能力を財務データから直接観測することが困難であるため，
実証モデルへの投入は行わなかった。
一方，英国企業では，親会社の財務余力や資本注入の履歴を proxy として
支援能力を構築することが可能であり，
Ordered Logit モデルにおいて $S$ を説明変数として投入した。

潜在変数 $y^*$ は



\[
y^* = \beta_\mu \mu + \beta_D D + \beta_\sigma \sigma + \beta_S S
\]



で与えられるため，支援能力の上昇は $y^*$ を押し上げ，
cutpoint $\tau_1, \tau_2$ を跨ぐ確率を低下させる。
その結果，倒産ステージの進行が抑制される。

\subsection*{10.4.3 倒産ステージを押し下げる構造的メカニズム}

支援能力が高い企業は，以下の理由により倒産ステージが進行しにくい。

\begin{enumerate}
    \item \textbf{倒産閾値が押し下げられる}：  
          支援能力 $S$ は倒産境界 $D$ を実質的に低下させ，
          倒産距離を拡大する。

    \item \textbf{外生ショックの影響を吸収できる}：  
          $\sigma$ が高い企業でも，支援能力があればショックの影響を緩和でき，
          $y^*$ の急落を防ぐことができる。

    \item \textbf{資金繰り悪化時の延命効果}：  
          親会社や金融機関からの支援により，
          キャッシュフローの逼迫が倒産に直結しにくくなる。

    \item \textbf{負債比率との相互作用によるリスク緩和}：  
          負債比率 $D$ が高い企業でも，支援能力があれば倒産閾値が下がり，
          stage 2 への移行確率が低下する。
\end{enumerate}

これらの構造的要因により，支援能力の上昇は倒産ステージを押し下げる方向に作用する。

\subsection*{10.4.4 新電力市場における構造的意味}

新電力企業は，以下の理由により支援能力が構造的に低い傾向がある。

\begin{itemize}
    \item 多くが独立系であり，親会社の財務支援を期待できない  
    \item 資本規模が小さく，内部留保が蓄積しにくい  
    \item 銀行融資が限定的で，信用補完が弱い  
    \item 市場価格変動によりキャッシュフローが不安定で，支援余力が蓄積しない  
\end{itemize}

このため，新電力企業は支援能力 $S$ が低い状態で事業を運営しており，
外部ショックが発生すると倒産閾値を押し下げる緩衝材が存在しない。
その結果，潜在変数 $y^*$ が急速に低下し，
倒産ステージが短期間で進行する構造的脆弱性が生じる。

したがって，支援能力 $S$ は倒産回避における中心的要素であり，
新電力企業の倒産リスクを規定する構造的メカニズムの中で
唯一「倒産ステージを押し下げる方向に作用する要因」として位置づけられる。

% 10.5 Ordered Logit の閾値構造が示す倒産の段階性
% ============================================================

\section{Ordered Logit の閾値構造が示す倒産の段階性}

本節では，Ordered Logit モデルの閾値構造（cutpoints）が，
新電力企業の倒産プロセスにおける段階性をどのように説明するかを検討する。
倒産は単なる二値のイベントではなく，財務悪化，事業撤退，法的倒産といった
複数のステージを経て進行する現象である。
Ordered Logit モデルは，この段階性を潜在変数 $y^*$ と複数の閾値（cutpoints）
によって数学的に整合的に表現する枠組みである。

\subsection*{10.5.1 潜在変数と閾値構造}

Ordered Logit モデルでは，倒産ステージは潜在変数 $y^*$ の位置によって決定される。
潜在変数は



\[
y^* = \beta_\mu \mu + \beta_D D + \beta_\sigma \sigma + \beta_S S + \varepsilon
\]



で与えられ，企業の財務状態や外部ショック感応度を統合した
「倒産リスクの連続量」を表す。
この連続量が複数の閾値（cutpoints）をどこまで超えるかによって，
観測される倒産ステージが決まる。



\[
\text{stage} =
\begin{cases}
0 & (y^* < \tau_1) \\
1 & (\tau_1 \le y^* < \tau_2) \\
2 & (\tau_2 \le y^*)
\end{cases}
\]



この構造により，倒産ステージは連続量 $y^*$ の非線形的な写像として表現される。

\subsection*{10.5.2 閾値を跨ぐときに倒産確率が急変する構造}

Ordered Logit の確率式は以下で与えられる。



\[
\begin{aligned}
P(\text{stage}=0) &= \Lambda(\tau_1 - y^*),\\
P(\text{stage}=1) &= \Lambda(\tau_2 - y^*) - \Lambda(\tau_1 - y^*),\\
P(\text{stage}=2) &= 1 - \Lambda(\tau_2 - y^*),
\end{aligned}
\]



ここで $\Lambda(\cdot)$ はロジスティック分布の累積分布関数である。
この式から明らかなように，潜在変数 $y^*$ が cutpoint に近づくと，
確率は急激に変化する。

すなわち，

- $y^*$ が $\tau_1$ に近づくと財務悪化ステージの確率が急上昇し，
- $y^*$ が $\tau_2$ を下回ると倒産ステージの確率が急上昇する。

この「閾値を跨ぐ瞬間の急変」は，倒産が段階的に進行するという
実際の企業行動と整合している\footnote{
第9章で示した倒産ステージ確率曲線は，この閾値構造の非線形性を
日本企業と英国企業で対照的に示している。
日本企業の場合，$y^*$ が $\tau_2$ に接近すると，
stage 2（倒産）の確率がほぼ垂直に立ち上がる形状を示し，
外生ショックにより $y^*$ がわずかに低下しただけで
倒産確率が急峻にスパイクする。
これは，収益性の低さ，負債依存度の高さ，ショック感応度の高さ，
支援能力の低さという「四重の脆弱性」により，
$y^*$ が恒常的に cutpoint 近傍に位置しているためである。

一方，英国企業の確率曲線は，stage 2 の確率が緩やかに上昇する形状を示し，
$y^*$ が cutpoint を跨ぐ際の急峻性が弱い。
これは，容量市場や CfD，SoLR などの制度的緩衝材，
および親会社の支援能力により，
$y^*$ が cutpoint から一定の距離を保ちやすい構造にあるためである。

したがって，第9章の確率曲線は，
Ordered Logit の閾値構造が企業の構造的脆弱性によって
「急峻な非線形進行（日本）」と「緩やかな進行（英国）」という
異なる形で現れることを視覚的に示している。}。

\subsection*{10.5.3 倒産の段階性を説明する理論的含意}

Ordered Logit の閾値構造は，倒産が以下のような段階的プロセスであることを示す。

\begin{enumerate}
    \item \textbf{財務悪化は連続的に進行する}：  
          $\mu$ の低下や $\sigma$ の上昇により $y^*$ が徐々に低下する。

    \item \textbf{一定の閾値を超えるとステージが非線形的に変化する}：  
          cutpoint を跨ぐと確率が急変し，stage 0 → stage 1 → stage 2 と進行する。

    \item \textbf{倒産は「突然起こる」のではなく，閾値を跨ぐことで発生する}：  
          倒産ステージ 2 の確率が倒産直前にスパイクする現象は，
          閾値構造の数学的性質と整合する。

    \item \textbf{外部ショックは閾値を一気に跨がせる可能性がある}：  
          $\sigma$ が高い企業では，市場価格急騰が $y^*$ を急落させ，
          短期間で複数の閾値を跨ぐ。
\end{enumerate}

この「閾値を跨ぐ瞬間の急変」は，倒産が段階的に進行するという
実際の企業行動と整合しており，Ordered Logit の閾値構造は
倒産の段階性を理論的に位置づける。

\subsection*{10.5.4 英国企業の倒産ステージとの整合性}

英国企業の倒産ステージは

\begin{itemize}
    \item Active  
    \item In administration  
    \item Liquidation  
    \item Dissolved  
\end{itemize}

という明確な法的段階構造を持つ。
Administration は財務悪化の法的段階であり，
Liquidation は事業清算の段階である。

Ordered Logit の閾値構造は，この英国の倒産プロセスと極めて整合的であり，

- $y^*$ が $\tau_1$ を下回ると Administration に入り，
- $y^*$ が $\tau_2$ を下回ると Liquidation に至る，

という段階的進行を理論的に説明することができる。

\subsection*{10.5.5 倒産ステージ推移の構造的解釈}

以上より，Ordered Logit の閾値構造は，

\begin{itemize}
    \item 倒産は連続量ではなく段階的に進行する  
    \item 閾値を跨ぐ瞬間に確率が急変する  
    \item 外部ショックが閾値を跨がせることで倒産が発生する  
    \item 財務悪化は閾値に近づくことで倒産リスクを高める  
\end{itemize}

という倒産の本質的特徴を数学的に表現している\footnote{
第9章で示した倒産ステージ確率曲線（日本企業・英国企業）は，
Ordered Logit の閾値構造が「閾値を跨ぐ瞬間に確率が急変する」ことを
実証的に裏付けている。
日本企業の倒産企業では，倒産直前に $P(\text{stage}=2)$ が
ほぼゼロから急峻にスパイクする形状を示し，
潜在変数 $y^*$ が cutpoint $\tau_2$ をわずかに下回っただけで
倒産確率が跳ね上がる非線形性が視覚的に確認できる。
一方，英国企業の確率曲線は，制度的緩衝材や支援能力により
$y^*$ が cutpoint から一定の距離を保ちやすく，
$P(\text{stage}=2)$ が緩やかに上昇する形状を示す。
これらの図表は，Ordered Logit の閾値構造が
「cutpoint を跨ぐ瞬間の急変」という非線形性を持つこと，
そしてその非線形性が企業の構造的脆弱性によって
異なる形で現れることを実証的に示している。}。

したがって，Ordered Logit の閾値構造は，
新電力企業の倒産ステージ推移を理解するうえで不可欠な理論的枠組みであり，
倒産の段階性を説明する中心的なメカニズムである。

% 10.6 日本企業と英国企業の構造的比較
% ============================================================

\section{日本企業と英国企業の構造的比較}

本節では，9.1～9.6節（日本企業）および9.7～9.12節（英国企業）で得られた
Ordered Logit 推定結果を，四要素モデル（$\mu, D, \sigma, S$）の観点から
構造的に比較する。
両国の係数の違いは，単なる統計的差異ではなく，
市場構造・財務構造・制度構造の違いに起因する「構造的隔たり」である。
以下では，各要素ごとに日英の構造的差異を整理し，
倒産ステージ推移のメカニズムがどのように異なるかを検討する。

\subsection*{10.6.1 収益性（$\mu$）の構造的差異}

日本企業では，資産成長率（収益性）$\mu$ が倒産ステージを押し上げる方向に
有意に作用した。
これは，新電力企業が薄利構造であり，収益性の低下が即座に財務悪化へと
結びつくためである。

一方，英国企業では $\mu$ は非有意であった。
英国では，容量市場や CfD（差額決済契約）\footnote{
CfD（Contracts for Difference：差額決済契約）は，
英国政府が再生可能エネルギー事業者に対して導入している収益安定化制度である。
発電事業者は，政府が提示する「ストライク価格」と市場価格（リファレンス価格）の
差額を政府と相互に決済することで，市場価格変動の影響を大幅に緩和できる。
市場価格がストライク価格を下回れば政府が差額を補填し，
逆に市場価格が上回れば発電事業者が差額を返納する仕組みである。
この制度により，再エネ発電事業者は長期的な収益の安定性を確保でき，
短期的なスポット価格変動が倒産リスクに直結しにくい構造が形成される。
英国の新電力企業の多くは，親会社が CfD 対象の発電事業を保有しているか，
CfD によって安定化された電源を調達できるため，
日本企業と比べて収益の下支えが強く，$\mu$ が倒産ステージに反映されにくい。}などの制度により，
収益の下支えが存在し，短期的な収益変動が倒産ステージに直結しにくい。
この制度的緩衝材が，日本企業との構造的隔たりを生み出している。

\subsection*{10.6.2 負債負担（$D$）の構造的差異}

日本企業では，負債比率 $D$ が倒産ステージを押し上げる方向に有意であった。
新電力企業は参入初期の設備投資やシステム投資により負債依存度が高く，
負債比率の上昇が倒産閾値を押し上げる構造が強く働く。

英国企業では $D$ は非有意であった。
英国の新電力企業は，親会社の財務支援や資本注入が比較的多く，
負債比率が高くても倒産閾値が緩和されるケースが存在する。
この「支援能力の存在」が，日本企業との構造的隔たりを形成している。

\subsection*{10.6.3 外部ショック感応度（$\sigma$）の構造的差異}

日本企業では，外部ショック感応度 $\sigma$ が正で有意となり，
市場価格急騰が倒産ステージを押し上げる主要因となった。
特に，JEPX スポット価格の急騰や燃料価格高騰が，
キャッシュフローを直接的に悪化させる構造が強い。

英国企業では，abs\_change や roll\_std\_3m が負で有意となり，
ショック感応度が倒産ステージを押し上げる方向に作用する点は共通であるが，
その符号構造は日本企業と異なる。
これは，英国の市場制度（容量市場，CfD，SoLR）がショックの影響を部分的に吸収し，
ショックが倒産ステージに反映されるタイミングが異なるためである\footnote{
英国政府の「Contracts for Difference and Capacity Market Scheme Update 2025」では，
CfD が市場価格変動を抑制し，低炭素電源の収益を安定化させる制度であることが明記されている
（CfD はストライク価格と市場価格の差額を決済することで，価格ショックを緩和する仕組みを提供する）。
また，Ofgem の「Annual Report on the Operation of the Capacity Market in 2025–26」では，
容量市場が電力供給の安定性を確保し，需給ショックの影響を緩和する政策的緩衝材として機能していることが示されている。
これらの制度により，英国企業は短期的なスポット価格変動や需給ショックの影響を直接受けにくく，
ショックが潜在変数 $y^*$ を cutpoint に到達させるタイミングが日本企業とは異なる構造が形成されている。}。
すなわち，構造原理は共通であるが，制度構造の違いが係数の符号に反映されている。

\subsection*{10.6.4 支援能力（$S$）の構造的差異}

日本企業では，支援能力 $S$ を財務データから観測できず，
実証モデルに投入することができなかった。
多くの新電力企業が独立系であり，親会社の財務支援を期待できないため，
支援能力が構造的に低い。

英国企業では，親会社の財務余力や資本注入の履歴を proxy として
支援能力を構築することが可能であり，
$S$ が倒産ステージを押し下げる方向に作用することが確認された\footnote{
英国企業における「親会社の財務余力・資本注入」が倒産回避能力として機能する事例は，
複数の公的レポートで確認されている。
第一生命経済研究所（2024）は，英国最大の水道会社の経営不安に関する報告の中で，
親会社が追加出資を見送ったことで子会社の倒産リスクが急上昇した事例を示しており，
親会社の財務余力が子会社の経営安定性に直接影響することを指摘している
（親会社のデフォルトが子会社の資金繰り悪化に直結する構造）。
また，金融庁委託「諸外国の業者支援の取組に関する調査報告書」（2025）では，
英国金融機関が債務者企業の業況悪化時に，
親会社の財務状況や資本注入の可能性をモニタリングし，
支援余力を倒産回避能力の重要な指標として扱っていることが示されている。
これらの事例は，親会社の財務体力・資本注入履歴を
支援能力 $S$ の proxy として構築できることを裏付けるものである。}。
英国企業は支援能力が高く，倒産閾値が緩和されるため，
日本企業よりも倒産ステージが進行しにくい構造を持つ。

\subsection*{10.6.5 日英比較が示す構造的含意}

以上の比較から，以下の構造的含意が得られる。

\begin{itemize}
    \item 日本企業は，収益性の低さ，負債依存度の高さ，ショック感応度の高さ，
          支援能力の低さという「四重の脆弱性」を抱えている。
    \item 英国企業は，制度的緩衝材（容量市場，CfD，SoLR）と支援能力により，
          倒産ステージが進行しにくい構造を持つ。
    \item 四要素モデルの構造原理は日英で共通であるが，
          各要素の強度（係数）は市場構造・制度構造の違いにより大きく異なる。
    \item 日本企業の倒産は「構造的脆弱性の累積」により発生し，
          英国企業の倒産は「制度的緩衝材が機能しない例外的ケース」として発生する。
\end{itemize}

したがって，日英比較は，倒産ステージ推移が単なる財務指標の変化ではなく，
市場構造・制度構造の違いによって規定される「構造的現象」であることを示している。

\section{本章のまとめ：構造的脆弱性こそ倒産の本質}

本章では，四要素モデル（$\mu, D, \sigma, S$）と Ordered Logit の閾値構造を用いて，
新電力企業の倒産ステージ推移を構造的に解釈した。
その結果，倒産は単なる財務指標の悪化や単発の外部ショックによって
偶発的に発生する現象ではなく，
企業が内包する構造的脆弱性が累積し，閾値を跨ぐことで段階的に進行する
「構造的現象」であることが明らかとなった。

四要素モデルの各要素は，倒産ステージ推移の異なる側面を規定している。

\begin{itemize}
    \item 収益性（$\mu$）は企業価値の期待成長率を規定し，
          その低下は倒産距離を縮小させる。
    \item 負債負担（$D$）は倒産閾値を押し上げ，
          財務柔軟性を低下させる構造的リスク要因である。
    \item 外部ショック感応度（$\sigma$）は市場価格変動の影響を増幅し，
          閾値を跨ぐ非線形的なステージ進行を引き起こす。
    \item 支援能力（$S$）は倒産閾値を押し下げる唯一の緩衝材であり，
          倒産ステージの進行を抑制する\footnote{
日本企業における支援能力 $S$ は，主として親会社や自治体による
直接的な資金支援（資本注入，信用補完，融資保証）を指す。
新電力企業の多くは資本規模が小さく，親会社の財務余力が
倒産回避能力に直結する構造を持つため，
$S$ は「直接的な資金支援能力」として解釈される。

一方，英国企業では，支援能力は必ずしも親会社の直接支援に限定されず，
容量市場（Capacity Market），CfD（差額決済契約），SoLR（Supplier of Last Resort）
といった制度的緩衝材が収益の下支えとして機能する。
これらの制度は，市場価格の急騰や需給ショックの影響を部分的に吸収し，
企業のキャッシュフロー悪化を緩和する役割を持つため，
英国では「制度的支援能力」が $S$ の一部として機能する。
したがって，日本企業の $S$ が「直接的支援」であるのに対し，
英国企業の $S$ は「制度的緩衝材を含む広義の支援能力」として位置づけられる。}。
\end{itemize}

Ordered Logit の閾値構造は，これら四要素が潜在変数 $y^*$ を通じて統合され，
cutpoint を跨ぐ瞬間に倒産ステージが非線形的に変化するという
倒産の段階性を数学的に表現する枠組みである。
倒産ステージ 2 の確率が倒産直前にスパイクする現象は，
閾値構造の理論的性質と完全に整合している。

さらに，日本企業と英国企業の比較から，
倒産ステージ推移は財務指標の違いではなく，
市場構造・制度構造の違いによって規定される「構造的隔たり」であることが示された。
日本企業は，収益性の低さ，負債依存度の高さ，ショック感応度の高さ，
支援能力の低さという四重の脆弱性を抱えており，
外生ショックが発生すると閾値を一気に跨ぎ倒産ステージが急速に進行する。
一方，英国企業は制度的緩衝材や支援能力により，
倒産ステージが進行しにくい構造を持つ。

本研究では，日本企業の分析を補完する目的で英国企業の実証分析を追加したが，
その結果は日本企業の推定結果を単に後押しするものではなく，
むしろ日英の構造的相違を鮮明に示すものであった。
すなわち，英国企業の倒産ステージ確率は制度的緩衝材により緩やかに推移する一方，
日本企業では閾値近傍に張り付く構造的脆弱性が顕著であり，
日本の新電力市場が抱える弱点がより浮き彫りとなった。

以上より，新電力企業の倒産は，
財務指標の悪化や単発の外部ショックではなく，
ビジネスモデル・市場制度・財務構造に内在する
「構造的脆弱性」によって規定される現象である。
本章で示した構造的解釈は，
第11章で行う政策的含意の検討に向けた理論的基盤を提供するものである。
