\section{本章の目的と基本方針}

本章では，第4章で導出した倒産距離 $Z_{\text{lin}}$ の構造
（収益性 $\mu$，市場ショック感応度 $\sigma$，支援能力 $S$，倒産閾値 $D$）
を，日本の新電力企業の財務データ・市場データに写像するための
\textbf{データ構築・変数定義・前処理} を体系的に示す。

本章の目的は以下の三点である。

\begin{enumerate}
  \item 新電力企業の財務データ（決算公告）と市場データ（JEPX）を統合した
        月次パネルデータセットの構築
  \item 倒産距離 DD の構成要素（$\mu,\sigma,D,S$）の定義と採用根拠の明示
  \item 年度データを月次へ補間し，倒産距離 DD の月次推移を可視化
\end{enumerate}

これらの処理により，第9章の Ordered Logit 推定に必要な
\texttt{financial\_data.csv} を作成し，倒産距離 DD の動態を実証的に評価する基盤を整える。

\section{データ収集の全体像}

本研究で用いるデータは以下の三種類で構成される。

\begin{enumerate}
\item \textbf{財務データ}：官報に掲載された新電力企業の決算公告（年次）
\item \textbf{市場データ}：JEPX スポット市場価格（30分値・日次・月次）
\item \textbf{倒産データ}：破産・民事再生・登録取消・事業撤退の発生月
\end{enumerate}

財務データが取得可能であった新電力企業は 7 社であり，
分析期間は 2016 年 10 月から 2025 年 5 月までである。

倒産段階の定義は以下のとおりである。

\begin{itemize}
\item 法的倒産（破産・民事再生）
\item 小売電気事業の登録取消
\item 事業撤退
\end{itemize}

これに基づき，企業 $i$ の月 $t$ における倒産段階 $\text{default\_stage}_{i,t}$ を構築した。

\section{財務データの処理}

\subsection{抽出項目}

官報掲載の決算公告から以下の項目を抽出した。

\begin{itemize}
\item 資産合計，負債合計，純資産
\item 流動資産，固定資産
\item 流動負債，固定負債
\item 資本金，利益剰余金
\end{itemize}

\subsection{年次データの月次化}

財務データは年次であるため，以下の方法で月次に変換した。

\begin{enumerate}
\item 年次データを観測月に割り当てる（例：2020年決算 → 2020年3月）
\item 年次間を線形補間し，月次データを生成する
\end{enumerate}

\section{理論モデルの四要素の実証的写像}

本節では，理論モデルで導出した四要素
（収益性 $\mu$，市場ショック感応度 $\sigma$，支援能力 $S$，財務健全性 $D$）
を，実際の企業データに基づく観測可能な指標へと結び付ける。
これら四要素は，倒産距離 $Z_{\text{lin}}$ の構造を形成する中心的な構成要素であり，
理論的には連続的な潜在変数として定義されているが，
実証分析では財務諸表・市場データ・企業属性情報などの具体的なデータを用いて
その意味内容を定量化する必要がある。

本節の目的は，各要素がどのような実証的 proxy によって測定され，
どのような経済的根拠に基づいて選択されるのかを体系的に示すことである。
これにより，理論モデルで構築した倒産リスクの構造が，
実証データの世界においてどのように再現されるかが明確になり，
後続の Ordered Logit 推定における線形部分 $X\beta$ との対応関係が
一貫した形で理解できるようになる。

\subsection{収益性 $\mu$ の定義と採用根拠}

収益性 $\mu$ は総資産の対数差分



\[
\mu_{i,t} = \ln(\text{Assets}_{i,t}) - \ln(\text{Assets}_{i,t-1})
\]



として定義する。

本研究における収益性の定義は，理論モデルで想定される
「企業価値の期待成長率」を，観測可能な財務データにより
安定的に近似することを目的としている。
新電力企業では損益計算書の欠損や収益の変動が大きく，
営業利益率や純利益率を用いるとノイズが増大し，
倒産リスクの連続的な変化を捉える指標としては適切でない。
これに対して総資産は，企業価値の蓄積を反映するストック指標であり，
短期的な収益変動に左右されにくいという特徴を持つ。
さらに総資産の対数差分（log-diff）は外れ値に強く，
経済学において成長率の標準的な測定方法として広く用いられている。

以上の理由から，本研究では総資産の log-diff を
収益性 $\mu$ の実証的 proxy として採用する。

\begin{itemize}
\item 収益性は企業価値の期待成長率の proxy として機能する  
\item 損益計算書ベースの収益はノイズが大きく，新電力企業には不向き  
\item 総資産はストック指標であり，企業価値の蓄積を反映する  
\item log-diff は外れ値に強く，経済学で標準的な成長率指標である  
\end{itemize}

\subsection{外部ショック感応度 $\sigma$ の定義と採用根拠}

市場ショック感応度 $\sigma$ は，スポット価格の変化率



\[
r_t = \frac{P_t - P_{t-1}}{P_{t-1}}
\]



の標準偏差として定義する。

本研究における外部ショック感応度の定義は，電力スポット市場における
短期的な価格変動が企業の損益に与える影響を，統計的に安定した形で捉えることを目的としている。
新電力企業は卸電力市場への依存度が高く，価格の乱高下が直接的に収益構造へ波及するため，
市場ショックの強度を適切に測定することが倒産リスクの分析において不可欠である。

価格水準そのものの標準偏差を用いる方法も考えられるが，
価格レベルの違いによって変動幅が過大・過小に評価されるという問題があり，
スケール不変性が満たされない。
これに対して変化率（returns）の標準偏差は，
価格水準の違いを取り除き，純粋な変動性のみを抽出できるため，
市場ショックの大きさをより正確に捉えることができる。
また，変化率ベースのボラティリティは金融経済学において標準的な指標であり，
外部ショックの強度を測定する実証的 proxy として広く用いられている。

以上の理由から，本研究ではスポット価格の変化率の標準偏差を
外部ショック感応度 $\sigma$ の実証的 proxy として採用する。

\begin{itemize}
\item 価格水準の標準偏差ではスケール不変性が満たされない  
\item 変化率の標準偏差は市場ショックの大きさを適切に捉える  
\item 新電力企業は市場価格ショックに強く依存するため，$\sigma$ は不可欠  
\end{itemize}

\subsection{支援能力 $S$ の定義と採用根拠}

支援能力 $S$ は，親会社や主要株主からの財務支援の余力を表す指標である。
本研究の対象企業では支援能力が観測可能な形で現れていないため，
$S=0$ と設定する。
支援能力は倒産閾値を押し下げる効果を持ち，
倒産距離 DD を拡大させる方向に作用する。

本研究における支援能力の位置づけは，理論モデルで想定される
「外部からの資金補完によって倒産境界からどれだけ遠ざかるか」
という構造的役割を，実証データの世界でどのように扱うかを明確化することにある。
一般に，親会社の財務規模や信用力，資本関係の強さは，
企業が財務ショックを受けた際の緩衝材として機能し，
倒産閾値を引き下げることで倒産距離を拡大させる。
この効果は，理論モデルでは明確に定式化されている。

しかし，新電力企業の実証データでは，
親会社支援が財務指標に明示的に反映されるケースが極めて少なく，
支援の有無や規模を定量的に測定できる情報が存在しない。
また，親会社が存在していても，
支援が制度的に保証されているわけではなく，
財務諸表や市場データから支援能力を推定することは困難である。
このため，本研究では支援能力を実証的に扱う際に
「観測可能な支援効果は存在しない」と解釈し，
$S=0$ を採用する。

この設定により，倒産距離の構造は
収益性 $\mu$，市場ショック感応度 $\sigma$，財務健全性 $D$ の三要素によって決定され，
支援能力が倒産リスクを左右する可能性は理論的には保持しつつも，
実証モデルでは観測可能な情報に基づく簡潔な構造として整理される。

\subsection{倒産閾値の代理変数 $D$（負債比率）の定義と採用根拠}

負債比率は



\[
D_{i,t}=\frac{\text{Liabilities}_{i,t}}{\text{Assets}_{i,t}}
\]



と定義する。負債比率が高い企業ほど倒産閾値が押し上げられ，
倒産距離が短縮する方向に作用する。

本研究における負債比率の採用は，理論モデルで想定される倒産閾値
（企業価値が一定水準を下回ったときに倒産が発生する境界）の
実証的 proxy を，観測可能な財務指標によって安定的に近似することを目的としている。
理論モデルでは倒産閾値は負債の名目価値に依存するが，
実証データでは企業価値や負債の市場価値を直接観測することができない。
そのため，財務諸表に基づく負債比率を用いることで，
「企業がどれだけ負債に依存しているか」という財務構造を通じて
倒産閾値の高さを捉えることが可能となる。

負債比率は，資産に対する負債の相対的な大きさを示すストック指標であり，
企業の財務的脆弱性を反映する代表的な指標として広く用いられている。
負債が増加すると，返済負担や資金繰りリスクが高まり，
企業価値が一定であっても倒産境界に近づきやすくなる。
この構造は，理論モデルにおける「倒産閾値の押し上げ」という概念と整合的であり，
負債比率を倒産閾値の代理変数として用いることは，
理論と実証の双方において合理的である。

以上の理由から，本研究では負債比率 $D$ を倒産閾値の実証的 proxy として採用し，
倒産距離の構造における閾値項を観測可能な財務データにより表現する。

\section{倒産距離 DD の月次計算}

倒産距離 DD は



\[
DD_{i,t} = \mu_{i,t} - \sigma_t D_{i,t} + S_i
\]



として計算する。

本研究では，倒産距離を月次ベースで評価するために，
企業財務データ（年度値）と市場データ（高頻度データ）を
同一の時間粒度へ整合させる必要がある。
財務指標は通常，年次または四半期でしか公表されない一方，
スポット価格などの市場データは日次・月次で観測される。
このままでは，理論モデルで想定される
「収益性・市場ショック・財務健全性が同時に作用する倒産距離」
を時系列的に評価することができない。

そこで本研究では，年度データを月次へ補間し，
市場データと結合することで，倒産距離 DD の月次推移を構築する。
補間には線形補間を用い，年度値を 12 か月に均等に割り付けることで，
財務指標が年度間でどのように変化したかを滑らかに再現する。
線形補間は，外れ値の影響を抑えつつ，
財務指標の趨勢を自然に反映できる点で実証研究において広く用いられる。

この月次補間により，年度データのみでは捉えられない
「財務状態の悪化がどの月に顕在化したか」
「市場ショックが企業の倒産距離にどの程度影響したか」
といった時系列的な構造を精緻に把握できるようになる。
特に新電力企業では，市場価格の急変動が財務状態に即時的に波及するため，
月次粒度で倒産距離を評価することは，倒産リスクの実証分析において不可欠である。

\section{本章のまとめ}

本章では，従来の第6章（変数定義と採用根拠）を拡張し，
日本企業 7 社のデータ構築・変数定義・月次補間・倒産距離 DD の計算・記述統計を
すべて統合した。

\begin{itemize}
  \item 収益性 $\mu$，市場ショック感応度 $\sigma$，支援能力 $S$，負債比率 $D$ を
        理論モデルの四要素として実証的に定義した。
  \item 官報公告と JEPX データを統合し，年度データを月次補間して
        倒産距離 DD の月次推移を可視化した。
  \item 記述統計により，変数の分布と新電力企業の財務特性を確認した。
\end{itemize}

これらの処理により，第9章の Ordered Logit 推定に必要な
\texttt{financial\_data.csv} が整備され，
倒産距離 DD の動態を実証的に評価する基盤が完成した。
